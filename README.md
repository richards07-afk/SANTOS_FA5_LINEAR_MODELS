## Research question
Does penguin body mass differ according to species and sex, and does the effect of species on body mass depend on sex?

## Dataset
The project uses the Palmer Penguins dataset developed by Allison Horst and collaborators. The response variable is `body_mass_g`; the explanatory categorical variables are `species` and `sex`. The CSV is included in `data/penguins.csv`.

Source: https://github.com/allisonhorst/palmerpenguins

## Files
- `data/penguins.csv` — raw dataset
- `R/FA5_Linear_Models.R` — complete reproducible base-R analysis for Parts A–G
- `figures/body_mass_by_species.png` — boxplot by species
- `figures/body_mass_by_sex.png` — boxplot by sex

## Reproduce the analysis
1. Download or clone this repository.
2. Open R or RStudio and set the working directory to the repository root (the folder containing this README).
3. Run:

```r
source("R/FA5_Linear_Models.R")
```

The script uses base R only and does not require installing extra packages. It prints data structure, summaries, missing-value counts, descriptive statistics, one-way ANOVA, dummy-variable regression, two-way ANOVA, and full regression output. It writes generated tables and figures to `output/` and `figures/`.

## Data preparation
The raw dataset has 344 rows. The analysis excludes rows missing `body_mass_g`, `species`, or `sex`, leaving 333 complete cases (11 rows excluded). `species` is ordered with Adelie as the reference category and `sex` with female as the reference category for regression interpretation.

## Statistical methods
- Descriptive statistics and boxplots
- One-way ANOVA: `body_mass_g ~ species`
- Dummy-variable regression using Adelie as the reference species
- Two-way ANOVA: `body_mass_g ~ species * sex`
- Full regression with species, sex, and their interaction
- Interaction plot of mean body mass by species, with separate lines for sex

## Main findings
- Overall mean body mass: 4,207.06 g (SD 805.22 g; n = 333).
- Mean body mass is highest for Gentoo penguins (5,092.44 g).
- Male mean body mass (4,545.68 g) exceeds female mean body mass (3,862.27 g).
- One-way ANOVA finds a statistically significant species effect, F(2, 330) = 341.895, p < 0.001.
- In the two-way model, species and sex main effects are statistically significant, and the species-by-sex interaction is significant, F(2, 327) = 8.757, p = 0.000197.
- The interaction means the male–female difference is not constant across the three species.
